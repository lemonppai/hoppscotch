# 2026-11-09

## 修复 pnpm install 失败（isolated-vm 原生模块）

**现象**：`pnpm install` 在 `isolated-vm@6.1.2` 的 install 脚本处失败：
`'node-gyp.cmd' 不是内部或外部命令` → `ELIFECYCLE Command failed with exit code 1`。

**根因**：
- isolated-vm 自带 `prebuilds/win32-x64/isolated-vm.abi127.node`（Node 22 可用），无需编译。
- install 脚本为 `node-gyp-build || node-gyp rebuild`。`node-gyp-build` 内部先跑 `node-gyp-build-test`，该步在 pnpm 脚本环境下失败（stderr 被 bin.js 静默吞掉），于是回退到 `node-gyp`；系统未安装 node-gyp（也无 VS Build Tools），导致整个 install 失败。
- 另发现 pnpm 在 `isolated-vm/node_modules` 下的依赖 junction 链接不完整（只有 `.bin`），属中断/环境残留，会加剧 prebuild 检测失败。

**修复**：根 `package.json` 的 `pnpm` 配置中，将 `isolated-vm` 从 `onlyBuiltDependencies` 移除，加入新增的 `ignoredBuiltDependencies`（pnpm 10 官方机制，跳过其 build script）。运行时由 `node-gyp-build` 自动加载随包预编译二进制。

**验证**：`pnpm install` exit 0（15m31s，含 prisma generate / js-sandbox build / gql-codegen 全部 Done）；
`require('isolated-vm')` + `Isolate`/`evalSync('1+1')=2` 运行正常。

**注意**：环境里 `wmic.exe` 被安全策略屏蔽（沙箱），且 `~/.npmrc`、项目 `.npmrc` 读取被安全审批拦截，未进一步深挖 pnpm 脚本环境差异。

## 修复 selfhost-web 启动崩溃（vite-plugin-pages-sitemap）

**现象**：dev 启动时 `Cannot read properties of undefined (reading 'endsWith')`，出在 `vite-plugin-pages-sitemap` 的 `removeMaybeSuffix`。

**根因**：项目根目录缺少 `.env`（只有 `.env.example`）。`vite.config.ts` 的 `loadEnv(...)` 读不到 `VITE_BASE_URL`，sitemap 插件的 `hostname` 为 undefined。

**修复**：`cp .env.example .env`。

**验证**：`pnpm run dev:vite`（@hoppscotch/selfhost-web）启动成功，生成 `.sitemap-gen/sitemap.xml` 和 `robots.txt`。注意 3000 端口被占用时 vite 会自动换 3001。
