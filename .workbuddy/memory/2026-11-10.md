## OpenAPI URL 导入的集合支持「刷新更新接口」（20:30 完成）

需求：通过 `/#/import?url=...&type=openapi` 导入的集合，能一键重新拉取 spec 并更新接口，而不是重新导入一个新集合。

### 数据模型（hoppscotch-data）
- `collection/v/12.ts`：v12 schema 内**追加** `apiSpecSource`（`{ type: "openapi-url", url, syncedAt }`，`.nullish().catch(null)`），**不升版本**——旧数据 undefined 可 parse，脏值退化为 null，避免触碰 backend/team 侧版本校验
- `collection/index.ts`：导出 `HoppCollectionAPISpecSource`；`translateToNewCollection` 透传该字段（否则持久化加载时丢失）
- 持久化无需改动：`validation-schemas` 用 `entityReference(HoppCollection)`，v12 声明过就不会被 zod strip

### 导入侧
- `pages/import.vue`：`handleImportSuccess(collections, { url, type })`，仅 `type === "openapi"` 且 url 为 string 时给根集合写 `apiSpecSource`，`syncedAt` 用导入时刻

### 刷新逻辑（新文件 `helpers/import-export/refresh/openapi.ts`）
- `mergeRefreshedCollection(current, incoming)` 纯函数：
  - 请求按 **`METHOD + endpoint`** 匹配（endpoint 形如 `<<baseUrl>>/users/<<id>>`，比 name 稳定，summary 改名很常见）
  - 匹配上 → 用新定义覆盖，但保留 `id`/`_ref_id`（tab、history、save context 依赖）
  - 只在 spec 里的 → 新增；只在本地（spec 已删）→ **保留**并计入 removed（不静默删除，避免打断打开的 tab）
  - 文件夹按 name 递归合并，本地独有文件夹保留
  - 集合级 auth/headers/variables/scripts/description **一律不覆盖**（用户配置）
  - diff：`{ added, updated, unchanged, removed, foldersAdded }`，`updated` 用排除 id/_ref_id 后的 JSON 比较，未变的不算更新
- `refreshOpenAPICollection(collection, deps?)`：fetch → importer → merge → 刷新 `syncedAt`；deps 可注入（`fetchSpec`/`importSpec`），测试无需 Worker/网络
- 错误码：`REFRESH_NO_SOURCE` / `FETCH_FAILED` / `PARSE_FAILED` / `EMPTY_SPEC`

### 写回 store
- `newstore/collections.ts`：新 dispatcher `replaceCollectionByRefId`（按 `_ref_id` 递归替换子树、保持位置）+ 导出 `replaceRESTCollectionByRefId(collection): boolean`（不存在时返回 false）
- 个人集合 `restCollectionStore.subject$` 有 persistence 订阅，dispatch 即落库

### UI
- `collections/Collection.vue`：菜单项「Refresh from OpenAPI」（`~icons/lucide/refresh-cw`，快捷键 `U`），仅 `collectionsType === "my-collections"` + `folderType === "collection"` + `data.apiSpecSource` 存在时显示；emit `refresh-collection`
- `MyCollections.vue`：透传 payload `{ pathOrID, collectionRefID, collection }`
- `collections/index.vue`：`refreshCollection` → 成功 `replaceRESTCollectionByRefId` + toast 汇总 `{added}/{updated}/{removed}`，失败按错误码 toast
- `locales/en.json`：`collection.refresh_from_source` / `refresh_success` / `refresh_fetch_failed` / `refresh_parse_failed` / `refresh_no_source` / `refresh_missing`

### 已知限制
- 团队空间（team-collections）不显示刷新入口：接口存在 GraphQL 侧，需要 create/update/delete 请求级 API，未做
- 文件/文本导入的集合没有来源信息，因此没有刷新入口
- spec 中已删除的接口/文件夹**保留**（刷新只增改），不提供"清理"选项
